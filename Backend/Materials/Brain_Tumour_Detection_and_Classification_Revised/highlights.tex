\section*{Highlights}

\begin{itemize}
\item Nine CNN, efficient CNN, and transformer models benchmarked under one protocol.
\item Perceptual hashing removes 19.3\% near-duplicate MRI images before splitting.
\item Top binary models reach 99.39\%, but 96.5--98.8\% on leakage-free test images.
\item Swin-Base leads multiclass subtype classification at 98.58\% accuracy.
\item EfficientNetB0 matches larger models using only 4.0 million parameters.
\end{itemize}
